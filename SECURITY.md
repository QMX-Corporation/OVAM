# Security Policy for OVAM

QMX Corporation takes the security of Ring 0 firmware architectures extremely seriously. Our core design implements the AEMos cryptographic engine to mitigate low-level vulnerabilities.

## 🛡️ Supported Versions
Only the latest active development branch on the official repository is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Core 0.1| :white_check_mark: |

## 🚨 Reporting a Vulnerability
If you discover any critical security vulnerability (such as a Side-Channel Attack vector, hardware fault injection exploit, or memory leaks), **do not open a public issue.** 

Please report all security vulnerabilities privately by contacting the Project Administrator directly through authorized community channels,my Server Discord (or in DM) or official QMX Corporation direct messages.
