# Product Support for OVAM

Welcome to the QMX Corporation support guidelines for the OVAM firmware ecosystem.

## 💬 Official Communication Channels
Do not open GitHub Issues for general questions, compiler setups, or architecture doubts. Use our official channels:
- **QMX Community Server (Discord):** [Join here](https://discord.gg/88hUjybuY5)

## 🛑 Before Asking
Before requesting support for compiling via `build.bat` or `build.sh`:
1. Verify that your `Clang/LLVM` and `Make` toolchains are properly installed in your system PATH.
2. Ensure your local environment complies with the strict 4GB RAM low-level memory map guidelines to prevent kernel thrashing.
