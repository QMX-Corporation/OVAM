# Project Governance - OVAM

## 👑 Benevolent Dictator for Life (BDFL)
The OVAM (Open Vallen Ard Man) project operates under a Benevolent Dictator for Life model. 

The Project Founder and Lead Architect, **dev12124** (João Guilherme da Silva Freitas Lima), maintains absolute veto power and final authority over all architectural designs, cryptographic integrations, and code merges within the QMX Corporation repositories.

## 🛡️ Core Rules for System Updates
1. **The Ultimate Veto:** No feature, driver patch, or system allocation table will be merged into the `main` branch without explicit, line-by-line administrative approval from the BDFL.
2. **Pull Request Quality:** If a proposed patch fails to comply with the low-level purism guidelines (such as introducing legacy bloatware, memory leaks, or incorrect pointer casting), the PR will be canceled immediately by the BDFL.
3. **Architecture Decisions:** Major changes regarding ACPI, NVRAM mapping, or the custom `.pxe` bootloader specification are unilaterally decided by the BDFL to ensure pure performance boundaries on hardware tracking platforms.
